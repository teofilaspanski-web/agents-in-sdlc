ここまでの2つの演習では、ユーザーエクスペリエンスを改善し、機能を追加する3つのタスクを Copilot クラウドエージェントに依頼しました。クラウドエージェントは非同期かつ自律的に作業しますが、タスクを監視することも重要です。

クラウドエージェントに割り当てたタスクは、GitHub.com の[エージェントページ][agents-page]など、さまざまなツールで管理できます。このミッションコントロールでは、オープンなプルリクエスト (PR) があるすべてのエージェントタスクを確認できます。Copilot が行った操作を調べたり、進行中のセッションを調整して作業の方向を導いたりできます。

このレッスンでは、次のことを行います。

- エージェントページでクラウドエージェントのタスクを監視します。
- 進行中のセッションを調整し、機能の追加を依頼します。

## シナリオ

ハイコントラストモードの作成をエージェントに割り当てた後、チームはライトモードも追加する良い機会だと考えました。サイトのスタイルを更新し、切り替え機能を追加する作業をすでに進めているため、ライトモードも含めるのが自然です。エージェントの作業を調整して、ハイコントラストとライトモードの両方を追加します。

## Copilot クラウドエージェントのタスクを確認する

Copilot クラウドエージェントに割り当てたタスクの現在の状態を確認します。

1. [Copilot エージェントページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインのタスクリストを確認します。次のようなタスクが表示されます。
   - コードベースのドキュメントを更新する。
   - ゲーム変更用の API を生成する。
   - Web サイトにハイコントラストモードを追加する。
3. 実行中のタスクを1つ選択し、Copilot が行った作業を確認します。次のような操作が含まれる場合があります。
   - リポジトリからコードをチェックアウトする。
   - Copilot が作業する環境を作成する。
   - MCP サーバーをセットアップする。
   - 割り当てられたタスクを完了するために、さまざまな手順を実行する。

> [!NOTE]
> 表示される手順は、Copilot の作業状況や採用した方法によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。追加の監視に使える PR と変更ファイルが表示されます。

## クラウドエージェントを調整する

実行中のタスクを確認したので、ハイコントラストモードを作業中の Copilot に、ライトモードの切り替えも含めるよう依頼します。

1. ハイコントラストモードの追加に関するセッションを選択します。表示される正確なタイトルは、Copilot が付けた名前や作業状況によって異なります。

   ![ミッションコントロールに表示されたアクセシビリティセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業が始まったことを示すメッセージが表示されるまで、数分間セッションを確認します。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

   ```plaintext
   While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
   ```

   ![エージェントページで、作業中のクラウドエージェントタスクを調整するダイアログが強調表示されている](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトに応答し、作業の流れに追加したことを確認します。

## Copilot に作業を続けさせる

Copilot は更新されたタスクに取りかかります。メッセージを送信した時点で実行していた手順が終わると、新しい依頼を作業の流れに含めます。

これまでと同様に数分かかります。その間に休憩し、これまでに学んだことを振り返りましょう。

## まとめと次のステップ

このレッスンでは、GitHub Copilot クラウドエージェントのタスクを監視して導く中心的な場所である Copilot エージェントページを確認しました。このミッションコントロールでは、進行中および完了したタスクを追跡し、実行中の作業を確認し、セッションの進行中に方向を変更して範囲の調整や追加の指示ができます。

次の内容を確認しました。

- ミッションコントロールとエージェントページでクラウドエージェントのタスクを監視しました。
- 進行中のセッションの方向を変え、機能の追加を依頼しました。

Copilot がアクセシビリティ機能の作業を完了したら、[Copilot が作成したプルリクエストを反復して改善します][next-lesson]。
