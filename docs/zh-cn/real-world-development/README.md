通过真实场景、完整应用和共享待办事项，了解 GitHub Copilot 如何融入软件开发生命周期。你将以迭代方式规划更改、编写代码、测试行为、审阅拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为棋盘游戏提供众筹平台，并采用开发者主题。团队的待办事项已作为 GitHub 议题创建完毕，你可以随时着手处理，其中包括筛选和分页等功能开发任务，以及无障碍和编码标准等质量改进任务。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。请选择适合构建方式的工作环境。每个工作坊都有各自的环境设置，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验 Plan 和 Autopilot 模式、说明、技能、自定义代理、Playwright 模型上下文协议（MCP）、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行代理会话、切换会话模式、协作使用画布，并管理 GitHub 议题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 议题分配给异步代理、引导其工作、监控进度，并审阅它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。使用 Copilot Chat 代理模式、MCP 服务器和自定义代理，全程无需离开编辑器。
